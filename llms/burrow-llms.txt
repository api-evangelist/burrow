# Burrow

> Burrow is a client reporting and operations platform for web agencies — WordPress, WooCommerce, GitHub, Stripe, and 20+ integrations in one event stream per client.

Burrow is built for multi-client web agencies — especially mixed-stack teams running WordPress, Shopify, Craft CMS, and custom builds — that need operations visibility, automated reporting, and client portals without stitching together per-CMS dashboards.

## Use cases

- [Agency operations dashboard — every client in one view](https://useburrow.com/use-cases/agency-operations): Stop switching between WordPress admin, GitHub, and Stripe for each client. Burrow unifies deploys, forms, orders, payments, and uptime in one timeline.
- [Client portal software for web agencies — live activity views](https://useburrow.com/use-cases/client-portals): Give clients a live, read-only view of deploys, forms, orders, and uptime — no admin access to WordPress, GitHub, or Stripe required.
- [Automated client reporting for web agencies — monthly reports](https://useburrow.com/use-cases/client-reporting): Generate monthly client reports automatically from real operational data — deploys, forms, orders, payments, and uptime. Stop screenshotting dashboards.
- [WordPress version and plugin tracking across client sites](https://useburrow.com/use-cases/cms-version-tracking): See which of your 40 WordPress sites run PHP 8.3, which have outdated WooCommerce, and which need core updates — one portfolio view, no logging into admin panels.
- [WooCommerce and ecommerce analytics for agencies — order reports](https://useburrow.com/use-cases/ecommerce-operations): Track WooCommerce orders, revenue, and checkout health across every client store — commerce data alongside deploys, forms, and billing.
- [Website form reporting for agencies — subfield analytics](https://useburrow.com/use-cases/form-monitoring): Track Gravity Forms, CF7, Fluent Forms, and Ninja Forms submissions across client sites — with subfield analytics on dropdowns, service types, and budget ranges.
- [Website maintenance reporting for agencies — care plan reports](https://useburrow.com/use-cases/maintenance-reporting): Document plugin updates, backups, uptime checks, form health, and security scans automatically — timestamped care plan reports that prove what clients pay for.
- [Manage WordPress, Craft CMS, and Statamic from one dashboard](https://useburrow.com/use-cases/multi-cms-agencies): ManageWP sees WordPress. Nothing sees the rest. Burrow normalizes WordPress, Craft CMS, Statamic, GitHub, and Stripe into one timeline per client.
- [Website monitoring for agencies — uptime, forms, and checkout](https://useburrow.com/use-cases/site-monitoring): Monitor uptime alongside form submissions, checkout health, deploys, and CMS changes — the context that tells you why a client site broke, not just that it did.
